# Triage Labels

Map canonical triage roles to the `Status:` strings in local issue files.

| Canonical role | Status string | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate this issue |
| needs-info | needs-info | Waiting on reporter for more information |
| ready-for-agent | ready-for-agent | Fully specified, ready for an autonomous agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill mentions a triage role, use its corresponding status string.
Edit the status column to change this repo's vocabulary.
